## 🛠️ Выполненные требования лабораторной работы №3

В ходе работы базовая страница была расширена с применением современных технологий раскладки (Flexbox и CSS Grid) и принципов адаптивного дизайна:

*   **[x] Flexbox-навигация:** Создано горизонтальное адаптивное меню в шапке сайта, сохраняющее строчную структуру и плавно переносящее ссылки по словам на мобильных экранах.
*   **[x] Flexbox-карточки («Исторические эпохи»):** Сверстан блок из 3-х карточек. Настроена адаптация под типы экранов: 3 карточки в ряд на десктопе, 2 на планшетах и 1 колонка на мобильных устройствах.
*   **[x] Grid-сетка («Артефакты музея»):** Создана двухмерная галерея экспонатов. Согласно условиям 19-го варианта: на смартфонах отображается ровно 1 колонка, на планшетах и ПК — 2 колонки.
*   **[x] Семантика и Доступность:** Даты обернуты в тег `<time datetime="...">`, реализованы заметные состояния фокуса (`:focus`) для интерактивных элементов, контрастность плейсхолдеров и текста доведена до соответствия спецификации \(\ge 4.5:1\).
*   **[x] Надежность верстки:** Исключены синтаксические ошибки внутри медиа-выражений, проверена корректность работы без появления горизонтального скролла.

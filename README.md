## 🛠️ Выполненные требования лабораторной работы №4 (Основы JavaScript)
В проект интегрирован обособленный файл сценария `script.js` (архивная логика вычислений), успешно выполняющий математические задачи 19-го варианта:
* **Инкапсуляция логики:** Вычисления распределены по изолированным функциям (`findMax`, `filterAncientArtifacts`, `calculateSum`, `analyzeYoungArtifacts`).
* **Алгоритмические конструкции:** Функция расчета доли находок использует цикл `for` и условное ветвление `if`.
* **Дополнительное условие:** Реализовано строгое ветвление при превышении максимального возраста артефакта значения в 3000 лет.

## ⚡ Выполненные требования лабораторной работы №5 (DOM и localStorage)
Интерфейс дополнен полноценным динамическим блоком «Хронологии событий», реализующим глубокую интеграцию с DOM API браузера:
* **[x] Разнообразие методов поиска элементов:** В коде одновременно задействованы механизмы выборки `getElementById`, `querySelector` и `querySelectorAll`.
* **[x] Динамическое управление DOM:** Реализовано программное создание элементов карточек событий через `document.createElement`, наполнение их текстовыми узлами и внедрение через `appendChild`, а также точечное удаление объектов при нажатии на индивидуальную кнопку удаления с помощью `.remove()`.
* **[x] Кастомизация темы отображения:** Кнопка смены оформления циклически переключает класс `theme-dark` у элемента `<body>`, динамически переопределяя цветовые переменные макета.
* **[x] Управление видимостью блоков:** Разработана опция «Свернуть хронологию», переключающая CSS-класс `.hidden` для изменения видимости контейнера.
* **[x] Устойчивость к сбоям:** Интегрирована валидация обязательного наличия узлов DOM перед выполнением сценария (предотвращает возникновение фатальных JS-ошибок при изменении разметки).
* **[x] Энергонезависимое сохранение данных (localStorage):** Выбранная пользователем тема оформления, признак скрытия панели хронологии и массив добавленных исторических событий полностью сохраняют свое состояние после ручной перезагрузки или закрытия вкладки браузера.

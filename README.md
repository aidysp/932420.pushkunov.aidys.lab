## 🛠 Выполненные требования лабораторной работы №4

В проект добавлен файл `script.js`, реализующий обработку массива с
возрастами исторических артефактов и демонстрирующий основные
конструкции JavaScript.

-   **\[x\] Ввод данных:** имя пользователя запрашивается с помощью
    `prompt`.
-   **\[x\] Вывод сообщений:** приветствие выводится через `alert`.
-   **\[x\] Массив данных:** создан массив из 7 чисел, представляющих
    возраст артефактов в годах.
-   **\[x\] Функция `findMax`:** определяет максимальный возраст
    артефакта.
-   **\[x\] Функция `filterAncientArtifacts`:** отбирает артефакты
    старше 1000 лет.
-   **\[x\] Функция `calculateSum`:** вычисляет суммарный возраст всех
    артефактов.
-   **\[x\] Цикл и подсчёт:** цикл проходит по массиву и считает молодые
    артефакты возрастом до 300 лет включительно.
-   **\[x\] Расчёт среднего значения и доли:** вычисляются средний
    возраст артефактов и процент молодых артефактов от общего
    количества.
-   **\[x\] Вывод результатов в консоль:** с помощью `console.log`
    отображаются исходный массив, список древних артефактов, сумма и
    максимальный возраст, а также количество и доля молодых находок.
-   **\[x\] Условная конструкция:** если максимальный возраст превышает
    3000 лет, в консоль выводится дополнительное сообщение.
-   **\[x\] Подключение скрипта:** файл `script.js` подключён к
    `index.html`.

## 📊 Пример результатов

Для тестового массива `[150, 450, 1200, 2500, 3200, 800, 5000]`:

-   **Средний возраст:** 1900 лет.
-   **Количество древних артефактов старше 1000 лет:** 4.
-   **Максимальный возраст:** 5000 лет.
-   **Количество молодых артефактов возрастом до 300 лет:** 1.
-   **Доля молодых артефактов:** около 14,3%.
-   **Дополнительное сообщение:** выводится, поскольку максимальный
    возраст превышает 3000 лет.

## ▶️ Запуск и проверка

1.  Откройте `index.html` в браузере.
2.  Введите имя в диалоговом окне `prompt`.
3.  Ознакомьтесь с приветствием в окне `alert`.
4.  Откройте инструменты разработчика браузера клавишей `F12` и
    перейдите на вкладку **Console**.
5.  Проверьте результаты вычислений и дополнительное сообщение.

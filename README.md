## 🛠️ Выполненные требования лабораторной работы №4

В проект добавлен изолированный файл сценария `script.js`, успешно решающий вычислительные задачи 19-го варианта:
*   **[x] Интерактивный ввод/вывод:** Запрос имени пользователя реализован через `prompt` с обработкой пустых строк (fallback на значение "Гость"). Приветственный текст выводится посредством `alert`.
*   **[x] Массив данных:** Обрабатывается массив из 7 числовых значений, отражающих реальный возраст музейных артефактов в годах.
*   **[x] Инкапсуляция логики:** Все вычислительные процессы разнесены по самостоятельным функциям (`findMax`, `filterAncientArtifacts`, `calculateSum`, `analyzeYoungArtifacts`).
*   **[x] Алгоритмические конструкции:** Функция вычисления доли молодых находок использует цикл `for` и условный оператор `if`.
*   **[x] Соответствие ТЗ:** Вывод итогового `alert` строго следует шаблону из задания. Логирование средних метрик и доли элементов выведено в `console.log`.
*   **[x] Дополнительное условие:** Реализовано точное условное ветвление, срабатывающее, если максимальный возраст артефакта строго превышает 3000 лет.

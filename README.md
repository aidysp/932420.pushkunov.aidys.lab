## 🛠️ Выполненные требования задания

В ходе лабораторной работы HTML-страница из ЛР №1 была оформлена с помощью CSS в соответствии с критериями 19-го варианта:
- [x] **Разделение стилей:** основной стиль вынесен во внешний файл `style.css`; применен ровно 1 inline-стиль; добавлено 1 правило во внутренний блок `<style>` в HTML.
- [x] **CSS-переменные:** в блоке `:root` объявлены цвета (основной терракотовый, акцентный темно-коричневый) и шрифты.
- [x] **Позиционирование:** продемонстрированы типы `static` (для секции навыков) и `absolute` (декоративная историческая печать).
- [x] **Состояния элементов:** корректно обработаны псевдоклассы `:hover`, `:active`, `:focus` и `:visited` для ссылок, интерактивных полей и кнопок.
- [x] **Эффекты варианта 19:** реализована текстура «старой бумаги» для контента, пунктирное подчеркивание ссылок при наведении и эффект «чернильного пятна» при фокусе на форме обратной связи.
- [x] **Доступность:** контрастность текста по отношению к фону составляет не менее 4.5:1.
